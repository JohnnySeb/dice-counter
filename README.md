# 🎲 Dice Counter

Petite app web mobile pour compter les scores quand on joue aux dés. Un seul fichier HTML, sans dépendance ni étape de compilation : on ouvre `index.html` dans un navigateur et ça marche.

## Fonctionnalités

- Écran de départ avec départs rapides **Js + Mimi** et **Famille** (couleurs des tortues ninjas : Js orange, Mimi mauve, Raphaël rouge, Loïck bleu).
- De 2 à 8 joueurs, chacun choisit son nom et sa couleur.
- Cartes des joueurs en **rangées**, **colonnes** ou **grille 2×2** (changeable en jeu via le bouton **STYLE!**).
- Calculatrice tactile pour ajouter (ou corriger) un score, avec animation *blink* + halo et un petit son.
- Premier à **10 000** points gagne : trophée animé, confettis et fanfare. 🏆

## Utilisation

Ouvre simplement `index.html` dans ton navigateur (double-clic), idéalement sur ton téléphone.

## Hébergement (optionnel)

Comme le fichier principal s'appelle `index.html`, tu peux l'héberger gratuitement avec **GitHub Pages** :
`Settings → Pages → Source : branche main / dossier root`. L'app sera alors accessible depuis une URL, sans rien installer.

## Techno

HTML + CSS + JavaScript pur (vanilla). Aucune librairie, aucun build. Facile à maintenir et à modifier.
